# Changelog

- Added Historical Signal Evaluation as a separate descriptive layer.
- Added 1-day, 3-day, and 7-day forward-return measurements.
- Added pooled signal statistics for all existing Kairon signals.
- Added asset-level signal statistics for cross-asset comparison.
- Added transparent sample-size notes and missing-future-data handling.
- Added historical occurrence CSV export and a standalone historical evaluation report.

- Distinguished the raw market-data period from the valid signal evaluation period.

- Added the overlapping-forward-window limitation.
- Clarified that raw historical observation counts are not effective independent sample sizes.
- Documented potential cross-asset dependence.
