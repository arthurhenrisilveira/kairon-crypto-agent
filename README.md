# Kairon Crypto Agent

Kairon Crypto Agent is an educational Python project for exploring crypto market analysis ideas.

The first version uses only public Binance market data, starting with public spot ticker prices. It does not use API keys, does not connect to a Binance account, and does not execute trades.

## Setup

1. Create and activate a Python virtual environment.
2. Install the project dependencies listed in `requirements.txt`, if needed.
3. Run the starter market snapshot:

```bash
python src/main.py
```

## Current Scope

- Fetch public spot prices from Binance.
- Print a simple market snapshot for selected assets.
- Provide placeholder modules for future indicators and strategy rules.

## Safety Note

This project is for education and research only. It is not financial advice and should not be used to trade real funds.
